CINEMATIC VIDEO PORTFOLIO — QUICK START

1. Install Node.js LTS: https://nodejs.org/
2. Extract this ZIP.
3. Open the extracted cinematic_video_portfolio folder in VS Code.
4. Choose Terminal > New Terminal.
5. Run: npm install
6. Then run: npm run dev
7. Open the local URL shown in the terminal (usually http://localhost:5173).

ADD YOUR VIDEOS
- Upload each video to YouTube (Unlisted is okay for a portfolio embed).
- Copy the video ID from its URL.
  Example: https://www.youtube.com/watch?v=ABC123xyz
  Video ID: ABC123xyz
- Open src/App.jsx and replace REPLACE_WITH_VIDEO_ID_1, _2, and _3 with your IDs.
- Edit titles and descriptions in the videos array.
- Change YOUR_EMAIL@example.com to your real email.

PUBLISH
- Push the project to GitHub, then import it into Vercel.
- This ZIP contains the website source; it is not online until you deploy it.
- Visitor analytics are not included yet; add an analytics provider after publishing.
